# BLC-C1 Project

## Business Lead Classification & Prioritization

BLC-C1 is a data analysis and machine learning project focused on classifying and prioritizing 297 business leads.

### Key Components
- AI Review Analysis
- Category Classification & Lead Prioritization
- Indian & Foreign Business Classification
- Excel, Power BI & Tableau Dashboards
- Data Analysis and Reporting

### Dataset
- 297 Businesses
- 207 Indian
- 90 Foreign

### Tools
Python • Pandas • NumPy • Scikit-learn • Excel • Power BI • Tableau • GitHub

### ML Outputs
- Review Priority: High / Medium / Low / No Review Data
- Category Priority: High / Medium / Low
- Business classification by country

### Project Status
Core analysis, models, and Excel outputs completed. Power BI and Tableau dashboards are being finalized.
